# Data dictionary

Generated by `make_data_dictionary.py` from the parquet files the
pipeline actually wrote. Do not edit by hand.

Source: MovieLens 32M (GroupLens) joined to IMDb `title.basics.tsv`.

## `catalog`

Full MovieLens catalog joined to IMDb title types, before TV removal.  
Rows: 85,080

| Column | Type | Description |
|---|---|---|
| `movieId` | `str` | MovieLens movie identifier. Primary key of movies_dim; joins every table. |
| `title` | `str` | Film title with the trailing release year stripped off. |
| `genres` | `str` | Pipe-separated MovieLens genre labels, or '(no genres listed)'. |
| `imdbId` | `str` | IMDb identifier from links.csv, without the 'tt' prefix. |
| `tconst` | `str` | Zero-padded IMDb identifier ('tt0114709') used for the IMDb join. |
| `titleType` | `str` | IMDb title type used to drop television. 'unknown' where unmatched. |
| `year` | `str` | Release year parsed from the raw MovieLens title. Null where absent. |
| `clean_title` | `str` | Film title with the trailing release year stripped off. |
| `is_tv` | `str` | True where titleType is episodic television. These rows were dropped. |
| `is_film` | `str` | True where titleType is a film type (movie, tvMovie, video, short). |
